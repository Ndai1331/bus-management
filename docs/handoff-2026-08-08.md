## Chạy lần sau

Từ thư mục project:

```bash
./scripts/k8s-up.sh --kind
```

Sau khi script báo deployed, mở local UI bằng một terminal riêng:

```bash
kubectl -n hcs port-forward deployment/blazor 8088:8080
```

Rồi mở `http://127.0.0.1:8088/`.

Các lệnh kiểm tra nhanh:

```bash
kubectl -n hcs get pods
helm -n hcs status hcs
curl -fsS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8088/
```

## Việc còn lại trước production

- Tạo `hcs-tls` bằng certificate TLS thật và cấu hình DNS cho `HCS_PUBLIC_HOST`/`HCS_AUTH_PUBLIC_HOST`; Kind chỉ dùng được qua port-forward khi chưa có LoadBalancer/DNS phù hợp.
- Kiểm thử end-to-end Keycloak SSO, OpenIddict và phân quyền bằng tài khoản/realm thật.
- Hoàn thiện migration/import dữ liệu commercial sau dry-run; không dùng database nguồn làm target migration.
- Commit source sau khi review phần migration Community và cấu hình deployment.
- Không đưa PFX, database password, Keycloak secret hoặc MinIO credentials vào Git. Chúng thuộc `.env`, User Secrets hoặc secret manager.
